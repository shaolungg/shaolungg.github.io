首页开场使用用户提供的 `封面视频_20261105.mp4`，原始文件保留在用户提供的位置。

网页文件为 `opening.mp4`（1920×1080）与 `opening-mobile.mp4`（1280×720），H.264、30fps、保留约 44 秒完整剪辑，均启用快速起播。`opening-poster.webp` 是视频首帧，用于加载时和减少动态效果模式下的静止画面。

路径统一在 `content.js` 的 `heroVideo`、`heroVideoMobile`、`heroPoster` 配置。电脑使用全屏背景视频；手机保留完整 16:9 横幅，标题位于下方。默认静音循环，可暂停，尊重系统减少动态效果设置。
